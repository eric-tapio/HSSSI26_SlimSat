Detailed Description

Spacecraft Bus Time Management Class.

The ScBusTime class provides comprehensive time management functionality for the spacecraft bus system. It tracks epoch time, system uptime, and provides time synchronization capabilities. This class is still under development and may be expanded with additional timing features as mission requirements evolve.
