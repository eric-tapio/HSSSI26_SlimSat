Detailed Description

NMEA Lite Message Handler Class.

The NmeaMsgHandler class provides comprehensive NMEA-style message processing capabilities including message parsing, validation, command execution, and response generation. It supports checksum validation, circular buffer management, and integration with various SlimSat subsystems including payload, LoRa radio, GPS, and bus database operations.
