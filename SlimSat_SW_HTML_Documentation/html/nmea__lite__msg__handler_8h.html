Detailed Description

NMEA Lite Message Handler Header.

This header file defines the NmeaMsgHandler class which provides NMEA-style message parsing, validation, and command processing for the SlimSat system. It handles command parsing, checksum validation, response generation, and message buffering using a circular buffer system.
