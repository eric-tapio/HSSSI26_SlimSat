Detailed Description

Simple Timer Class.

The SimpleTimer class provides basic timer functionality with configurable intervals and enable/disable control. It uses the Arduino millis() function for timing and supports intervals up to 20 minutes. The timer can be used for periodic operations, timeouts, and scheduling.
