Detailed Description

SlimSat Command Constants Header.

This header file defines all command constants used in the SlimSat NMEA message handling system. It includes command IDs for bus operations, radio configuration, payload control, timing operations, and system management functions. These constants ensure consistent command identification across the entire SlimSat communication system.
