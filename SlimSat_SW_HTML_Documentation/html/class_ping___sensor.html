Detailed Description

Ping Ultrasonic Sensor Class.

The Ping_Sensor class provides ultrasonic distance measurement functionality using a Parallax PING sensor. It handles pulse generation, echo timing, and distance calculations in both inches and centimeters. The class manages the sensor pin configuration and timing operations.
