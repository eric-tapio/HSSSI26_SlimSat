Detailed Description

Main SlimSat Bus Controller Class.

The SlimSatBus class serves as the central coordinator for all SlimSat bus operations. It manages communication with the payload, handles command processing, coordinates LoRa radio operations, and maintains system timing and database operations. This class implements the main operational loop for the bus system.
